# 🎮 Stone Paper Scissor Game

An engaging and interactive browser-based Stone Paper Scissor game built using HTML, CSS, and JavaScript.
Challenge the computer, test your luck, and enjoy a smooth gaming experience with dynamic UI interactions and real-time score updates.

---

## 🚀 Overview

This project recreates the classic Stone Paper Scissor game with a modern and responsive interface.
The game uses JavaScript logic to generate random computer choices, track scores dynamically, and provide an enjoyable user experience directly in the browser.

---

## 🌟 Features

🎯 Real-Time Gameplay Experience
⚡ Dynamic DOM Manipulation
🤖 Random Computer Choice Generation
📊 Live Score Tracking System
🎨 Responsive and Interactive UI
🖱️ Smooth User Interactions
📱 Browser Compatible Design

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript

---

## 🎮 How to Play

* Choose Stone, Paper, or Scissor
* Computer generates a random move
* Winner is decided instantly
* Scores update automatically after every round
